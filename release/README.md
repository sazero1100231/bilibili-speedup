# Bilibili Speedup

[English](README.en.md)

非官方的 Chrome／Edge 擴充功能。它會測試 Bilibili 為目前影片提供的 CDN 路線並選擇可用路線；沒有安全候選時，維持原生播放。

> 不提供地區解鎖。實際效果會隨所在地、帳號權限與 CDN 狀態而異。

## 功能

- 自動測試並切換可用 CDN。
- 清除常見追蹤參數，封鎖部分遙測與推廣內容。
- 在瀏覽器本機記錄播放與節點狀態，方便排查卡頓。

## 安裝

需要 Chrome 或 Edge 120 以上版本。

1. 下載並解壓縮本專案。
2. 開啟 `chrome://extensions` 或 `edge://extensions`。
3. 啟用「開發人員模式」。
4. 選擇「載入解壓縮」：繁體中文介面請指定 `release`，英文介面請指定 `release-en`。

## 隱私

- 設定與診斷資料只保存在瀏覽器本機，不會自動上傳。
- 診斷預設關閉；開啟後會記錄播放頁的標準化網址（自動移除 query 與 fragment）、媒體／Presentation／路由識別碼、效能與 CDN 資料、事件明細及精確時間，以保留排障線索；可隨時關閉或清除。
- 回報播放問題前，請先從診斷面板按「啟用診斷並開始記錄」，再回到播放頁重現。面板會在匯出前同步作用中場次，且不允許把沒有播放場次的空白檔誤當成有效診斷。
- 匯出的診斷 JSON 是完整技術紀錄，可能包含可識別播放內容或使用情境的資料。分享前請逐項檢查並遮蔽，不要直接公開上傳。

## 開發

需要 Node.js 22 以上版本。

```powershell
npm test
npm run build:release
```

建置結果位於 `release`（繁體中文）與 `release-en`（英文）。
